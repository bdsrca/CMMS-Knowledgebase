# Assets

This folder contains public-safe visual assets used by the portfolio README.

## Published Assets

- `kb-hero-architecture.svg` - Editable high-level architecture from knowledge sources to cited AI answers.
- `ingest-pipeline.svg` - Editable asynchronous ingest flow from document save to searchable chunks.
- `hybrid-retrieval.svg` - Editable retrieval flow from user question to citations and confidence.
- `security-boundary.svg` - Editable tenant, role, and logging privacy boundaries.
- `ai-helper-annotated.png` - Sanitized AI helper mockup with answer, citations, confidence, next actions, and tenant-aware context.

Earlier PNG diagram exports may remain in the folder for reference, but the README uses the SVG files as the canonical portfolio diagrams.

## Public-Safety Notes

These assets use synthetic labels and sanitized examples. They should not include customer names, real tenant IDs, production URLs, credentials, real source IDs, or private operational content.
