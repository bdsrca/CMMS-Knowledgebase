# Assets

This folder contains public-safe visual assets for the portfolio case study.

## Published assets

- `kb-hero-architecture.svg` — high-level knowledge-base architecture.
- `ingest-pipeline.svg` — document save to searchable chunks.
- `hybrid-retrieval.svg` — keyword + semantic retrieval to cited answers.
- `security-boundary.svg` — tenant, role, and logging boundaries.
- `knowledge-lifecycle.svg` — source review, ingest, answer, and feedback loop.
- `retrieval-quality-scorecard.svg` — illustrative measurement framework.
- `use-case-leverage-matrix.svg` — prioritization matrix for CMMS knowledge-base use cases.
- `china-manufacturing-to-kb-map.svg` — China manufacturing context mapped to CMMS/EAM knowledge needs.

## Public-safety notes

All visuals use synthetic labels. They should not contain customer names, real tenant IDs, private URLs, credentials, real source IDs, or private operational content.
