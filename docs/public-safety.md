# Public-Safety and Sanitization Notes

This repository is built for public portfolio use.

## What is intentionally excluded

- private product branding;
- customer names;
- tenant IDs;
- production URLs;
- email addresses;
- credentials;
- real source IDs;
- real work-order IDs;
- private operational documents;
- raw production logs;
- vendor keys or provider configuration;
- screenshots that expose identities or internal identifiers.

## Screenshot policy

The screenshots in this repository are synthetic mockups. They show the workflow shape without copying private UI state.

## Code policy

The code samples are simplified. They show the design pattern:

- chunking;
- retrieval;
- rank fusion;
- citations;
- fallback behavior.

They do not expose database schema from a private application, private API routes, credentials, or production-specific implementation details.

## Industrial examples policy

Chinese industrial examples are based on public sources and used as context only. They are not claims that any named company uses this repository's implementation.
